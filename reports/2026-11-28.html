TigerTTS：NAR 打草稿 + AR 逐帧精修的 0.15B 生产级 TTS，单卡 RTF 0.05（约 20 倍实时），SEED 上 CER 1.09 / WER 1.67 双榜最低 ⭐

📅 2026-11-25👥 Dewei Kong
自回归语音 token 语言模型能做出高质量 TTS，但三个老问题一直在：延迟随序列长度线性增长、没有显式对齐时容易漏词或复读、离散码本限制音质上限。TigerTTS 换了个分工方式：用一个轻量非自回归（NAR）模型在显式对齐下先把整句话的 token 全「打草稿」，再由一个紧凑的自回归 LLM 逐帧精修。关键是草稿与 LLM 目标帧帧对齐、并从输入端注入，训练和推理保持一致。因为草稿够准，LLM 一步可以跨 3 帧 4 组一次预测 12 个 token，并用条件总相关上界把并行预测的损失压到接近无损。tokenizer 不用码本，走 FSQ、四组并行、约 1800 bps，规避码本坍缩。骨干只在输入 embedding 保留位置信息，从而可做精确 MLA 权重吸收、KV cache 减少 4 倍；解码用 CUDA Graphs + 图安全的多项分布采样器。Fast 模式让 NAR 生成器充当前缀合成器（RTF 0.03）先吐出前 500 ms，进一步压低首包延迟。最终单卡 RTF 0.05、约 20 倍实时：0.15B 骨干比 VoxCPM2 2B 的标准 PyTorch 推理快 5 倍、比 CosyVoice 2 快 16 倍，同时在 SEED 上拿到最低 CER 1.09 / WER 1.67，LibriSpeech test-clean 上 WER 2.22、NMOS 4.36、说话人相似度 0.820。Fast 模式产生的语义 token 还兼作强内容先验，明显减少掉词、循环和失控生成。

InstructTTS-OPD：用 on-policy 蒸馏拆开「指令遵循 / 发音正确 / 自然度」三个互相拉扯的目标，再用冲突感知速度融合消除跷跷板 ⭐

📅 2026-11-25👥 Haitao Li, Tian Tan, Yuguang Yang, Guanrou Yang, Wenhao Guan, Chenglin Li, Shan Yang, Xie Chen
指令遵循 TTS（Instruct-TTS）要一句话同时满足三件事：照指令的「方式」说、把字念对、听起来自然。现在主流做法是 RL 后训练，但三个目标塞进一个标量奖励、用 GRPO 一起优化时训练很不稳：目标之间互相竞争，共享的更新会漂向最好提升的那一个，典型表现就是此消彼长的跷跷板。作者改用 on-policy 蒸馏（OPD）：让学生在自己的 rollout 上同时去匹配多个单目标教师的速度场。落地前提是每个轴都得有靠谱奖励，这点论文做得很细——用蒸馏过的 Qwen-Omni 代理昂贵的 Gemini 评判器、用无方言数据算 WER 奖励、用 DNSMOS 替代带语言偏置的 UTMOS。然后分别用 GRPO 训三个单目标教师（指令遵循、WER、MOS），再 OPD 融合：每个 rollout 按数据域路由到指令或 WER 教师，同时都跟随 MOS 教师保质量。结果是「指令遵循 + 可懂度」可以同涨而不冲突，但质量目标和指令遵循仍正面打架，简单相加会把跷跷板带回来。为此提出冲突感知速度融合（conflict-aware velocity fusion）：融合前先把质量目标在与主目标相反的方向上做投影剔除。最终模型在三个目标上同时超过标量奖励 GRPO。

UMAI：冻住 Qwen3-ASR，靠一次贪心解码的中间值把「呃/嗯」找回来——AMI 上填充词 F1 从 12.2 提到 82.6，且不改动任何识别词 ⭐

📅 2026-11-25👥 Gyeongmin Kim
ASR 通常会把「呃」「嗯」这类填充停顿从转写里抹掉。用逐字转写数据微调能把它们找回来，但会把其余输出也带偏。这篇论文的观察很省事：大部分漏掉的填充词，其实已经藏在冻结的 Qwen3-ASR-1.7B 一次贪心解码过程记录下的数值里。UMAI（UM Aware Inference）对输出词之间的每个空隙，从解码器注意力定位到的音频窗口上池化帧级类别后验，再通过两级线性判别分析与解码器状态结合，最后用保序回归（isotonic regression）校准分数。全程没有参数用梯度下降训练过。输出上只插入 [uh] / [um] 标签，已识别的词一个都不改。留出的 AMI 评测集上填充词 F1 从 12.2 升到 82.6，Nyra 逐字基准（也是阈值选定集）上从 37.2 升到 96.5，总处理时间只多 14%。

BiSAT：语义与声学双分支共享索引的语音 tokenizer，配出零样本 TTS 系统 BiSAT-TTS——HF Daily Papers 入选

📅 2026-11-23👥 Y. Lu, L. Wang, S. Okada
语音语言模型把语音生成为离散 token 序列，tokenizer 就得在低码率下同时保住声学细节和语言内容。语义增强型 tokenizer 容易丢声学细节，声学导向的又保留太多变化让语言建模变难，统一型把两者塞进同一特征空间又会互相干扰，而且现有做法通常把声学表示对齐到冻结语义教师的固定目标上。BiSAT 用「共享索引」机制把两条分支耦起来：训练时声学分支和语义分支各有自己的编码器、码本和解码器，但每一帧用同一个共享索引，使两支的量化误差之和最小，最终只输出一条离散码序列，两个编码器联合优化、不依赖固定语义教师目标。基于 BiSAT 又做了 BiSAT-TTS：自回归文本-语音 LM + 条件流匹配声学解码器的零样本 TTS。重建、下游理解与诊断分析表明码流里语义和声学信息都保住了，在 in-the-wild 与域外语音上表现稳健，学到的码本表示互补；冻结码做理解的结果也支撑它作为 RL 后训练中 code-based reward model 的潜力。BiSAT-TTS 用更少训练数据就达到与 SOTA 语音 LM TTS 基线相当的水平。

首个「注意力头级」合成语音检测研究：删掉几个「反向头」无需重训，WavLM EER 相对降 13%、Wav2Vec2 降 22%

📅 2026-11-25👥 Mohamed Mallat, Michele Panariello, Massimiliano Todisco, Anthony Larcher, Nicholas Evans
自监督语音骨干已是合成语音检测的标准前端，逐层探针也已经弄清哪几层信号最强，但分析止步于此：一层里 12 个注意力头中到底是哪几个在做真伪判决，此前没人知道。本文首次在 ASVspoof 5 上对两个冻结骨干（WavLM-base、Wav2Vec2-base）做头级研究。逐头消融显示，只有少数几个头承载判决，另有一些头在主动反对判决；把这些反向头去掉，不重训就能降低等错误率：WavLM 相对降 13%，Wav2Vec2 相对降 22%。论文还给出一个免探针特征：伪造语音的注意力比真实语音更集中，这个差距本身就能把两者几乎区分到与完整表示相近的程度，并在每个骨干最具判别力的层上达到峰值。最后，攻击类型身份可以在每一个头上解码出来——说明这些头「做的事」不同，但「知道的东西」相同。

MSCD：免训练对比解码让音视频大模型真正「对上时间」，Daily-Omni 上分别 +2.2 / +2.8 个点

📅 2026-11-25👥 Minyeong Jeong, Yeonju Kim, Yong Man Ro
音视频大模型（AV-LLM）号称能表示音视频的时序结构，但它们是否真的用这套时序信息去关联「声音-视觉事件」，其实没人验证。作者设计了一个音视频同步探针：把音频整体平移，让被问到的声音与另一个视觉事件重叠。结果模型依然偏向原本对齐的那个事件，说明它对音视频时序对齐的变化很不敏感。为此提出 MSCD（Modality-Shift Contrastive Decoding）：一种免训练的解码方法，通过对比「保持对齐」与「破坏对齐」两种条件下的 logits，放大有对齐音视频支撑的预测；破坏方式是在固定另一模态的前提下，把音频或视频在时间上平移。两个 AV-LLM、三个基准上的实验证明 MSCD 有效，在 Daily-Omni 上让 OmniVinci 与 video-SALMONN 2+ 的准确率分别提升 2.2 与 2.8 个百分点，说明强调时序对齐也能惠及更宽的音视频理解任务。
