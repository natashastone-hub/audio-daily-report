📅 2026-11-22👥 Shadow0482，基于 nvidia/personaplex-7b-v1
PersonaPlex 是 NVIDIA 的 Moshi 架构全双工 speech-to-speech 模型，原版权重 BF16 约 16.74GB，对单卡消费级设备偏重。这个仓库给的是纯权重量化版：348 个线性权重矩阵做 int4（group size 64、对称、无符号 nibble，两值一字节，低 nibble 为偶数列），embedding、norm、输出头与 127 个小张量保持 FP16，Q4 主权重 5.17GB，同时给了 Q8（int8、按输出行一个 scale）。量化误差报告得比较实在：量化张量的平均相对误差 1.23e-2、最大 2.06e-2、源权重 FP16 溢出张量 0 个。仓库文件是完整的（量化 LM + Mimi codec + tokenizer + voice prompts + web UI），并附 personaplex_quant.py：把 int4 反量化回 FP16 再喂 stock PersonaPlex 代码，误差不变但显存占用回到 BF16 水平；真想以 4bit 常驻显存，需要运行时把 nn.Linear 换成量化线性层。作者明确未做语音基准评测，建议先自己听样本——Q4 预期比 Q8 掉得明显。许可证沿用 NVIDIA Open Model License。

Phonon-2 ONNX：浏览器里跑 Parakeet 系 ASR，8bit 编码器 610MB 走 ORT Web/WASM ⭐

📅 2026-11-23👥 onlyTheOnionNews，基于 FermionResearch/Phonon-2（源自 nvidia/parakeet-tdt-0.6b-v3）
面向 onnxruntime-web（WASM）的浏览器端语音识别导出。模型本体 Phonon-2 是 Fermion Research 从 NVIDIA Parakeet TDT 0.6B v3 再训练、量化编码器线性权重得来的英文 ASR，权重 CC-BY-4.0。三张图分工：encoder.onnx 是 FastConformer 编码器加投影，权重 8bit（按通道、缩窄值域），输入 features [1,T,128] 输出 [1,T',640]，每帧 80ms，约 610MB；decoder_step.onnx 是 token embedding + 2 层 640 维 LSTM + projector（fp32，61MB），步进式吃单个 token 与 h/c；joint.onnx 是 joint 网络（fp32，26MB），输出 [1,8198]——8193 个 token 加 5 个 TDT 时长槽。前端口径完全对齐 transformers 的 ParakeetFeatureExtractor：16kHz 单声道、预加重 0.97、512 点 STFT（400 点 Hann、hop 160、居中补零）、128 个 Slaney mel、log(x+2^-24)、按有效帧做无偏归一化。解码是 batch=1 的贪心 TDT：起点 token 8192，逐帧取 token argmax 与时长 argmax，blank 前进 max(duration,1)，遇到 EOS(3) 或帧尾停。作者也直说了 8bit 编码器的代价：13 秒测试片段里最后一个词和更早一个词会错，而 2.4GB 的全精度编码器与参考完全一致——上线前务必用自己的音频验。
