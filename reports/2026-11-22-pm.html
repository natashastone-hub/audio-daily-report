Qwen3-TTS 1.7B GGUF：官方权重转 llama.cpp，Q4_K_M 仅 1.04GB 且 WER/CER 仍为 0 ⭐

📅 2026-11-22👥 Moonbox (moonbox-dev)，基于 Qwen/Qwen3-TTS-12Hz-1.7B-Base
Moonbox 把 Qwen3-TTS 1.7B 转成了 llama.cpp 可用的 GGUF，覆盖 Metal / CUDA / Vulkan / CPU 四种后端。工程上值得看的是拆分方式：主模型文件只装 talker 主干，mmproj 文件统一装其余全部部件——说话人编码器、code predictor（1–15 号码本）、语音 tokenizer 的编码器（带转写做音色克隆时用）与解码器（码本还原成 24kHz 音频），所有精度共用同一份 mmproj 的 F16。量化损失给得很实在：Q4_K_M 1.04GB，WER/CER 双 0.0%，相似度 0.959/0.957，DNSMOS 3.18/3.01，RTF 0.35；Q8_0 1.85GB，RTF 0.37；F16 3.47GB，RTF 0.40。也就是说 4-bit 量化在音色相似度上几乎没掉（甚至略高于 BF16 的 0.954/0.960），DNSMOS 掉约 0.02。用法：llama.cpp b12621 以上的 llama-tts CLI（-m 主文件 + -mm mmproj，--tts-speaker-file 给参考音色、--tts-speaker-text 给参考转写），或 llama-server 的 /tts 与 /v1/audio/speech 接口（input、lang、speaker_ref_b64、speaker_ref_text、seed）。对想在本地或端侧跑带克隆的多语种 TTS 的团队，这是目前最省事的一条路：一个 1GB 文件 + 一个 840MB 编码器，不再依赖 PyTorch 栈。

📅 2026-11-22👥 Moonbox (moonbox-dev)，基于 Qwen/Qwen3-ASR-1.7B
同一批发布的 ASR 侧 GGUF，同样走 llama.cpp（Metal / CUDA / Vulkan / CPU），主模型文件装 Qwen3 文本解码器，mmproj 固定 F16 装音频编码器与 projector（llama.cpp 的 qwen3a 类型），两者缺一不可。各精度成绩：BF16 WER 1.45% / CER 1.42%（原始权重报 1.45 / 1.52），CUDA RTF 0.043；F16 与 BF16 基本同分、RTF 0.044；Q8_0 2.17GB，WER 1.49% / CER 1.45%，RTF 0.033；Q6_K 1.67GB，1.52% / 1.49%；Q5_K_M 1.47GB，1.47% / 1.52%；Q4_K_M 1.28GB，1.55% / 1.62%，RTF 0.045——四个量化档的 WER 波动只有 0.1 个百分点量级，实际选型可直接按内存挑。比平均值更有信息量的是它额外给了「与 BF16 转写逐字相同」的条数：Q8_0 为 375/400 与 197/200，Q6_K 362/400，Q5_K_M 341/400，Q4_K_M 316/400。这种分布口径能看出量化误差是集中在少数难句上、还是均匀劣化，比只看平均 WER 更适合判断线上风险。

CueBall Voice v0.3：把连续语音合成塞进初代 Intel 神经计算棒（Myriad-2），并公开没达标的指标

📅 2026-11-22👥 tablinum / Rack Lab
一个逆向工程趣味很强的发布：在初代 Intel Neural Compute Stick（Myriad-2，USB 03E7:2150）上跑连续语音合成，encoder、mel decoder 和完整 HiFi-GAN V1 声码器拆成三个 FP16 IR 图交给计算棒，主机侧只负责音素化（eSpeak NG）、时长展开和 WAV 落盘。约束很硬：单次最多 128 个音素 token、最多预测 512 帧 log-mel，输出 22.05kHz 单声道。四组同题对比（十个英文 prompt，Whisper Tiny 打分）：Full 版 37.9MB / 驻留合成中位数 10.5s / WER 28.6%；Student 版 17.1MB / 3.34s / 29.9%，吞吐是 Full 的 3.15 倍、NCS1 上 RTF 1.23；同模型 CPU ONNX 版 2.89s / 22.1%，Student CPU 版 0.79s / 26.0%。作者自己写明：两条硬件路径都没达到「WER < 14.8% + 300ms 预热延迟」的实验目标，且只测了可懂度、没测自然度与多说话人。MIT 许可。价值不在音质，而在于给出了一套「把 TTS 全链路拆成可上 NPU 的图」的完整工程记录与可复现测量数据。
